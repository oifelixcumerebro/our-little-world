A LITTLE PLACE CALLED US — V15 ONLINE PLAYLIST

This version adds an online Spotify-powered playlist. The five songs already in the playlist are linked to Spotify, so no copyrighted audio files are bundled in the app.

To add another online song: Our Little World -> Our Little Editor -> Edit Soundtrack -> paste a Spotify song link.

The full song playback is provided by Spotify. The app itself does not host copyrighted music.

For the PWA install experience, serve the folder over HTTPS rather than opening index.html directly from a file.
